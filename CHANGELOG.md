
- The repository is session-store: a repository is named after what it handles, a noun in the singular (plan N-1).
  Every name follows it (design P-1, E-2): the crates `polyspec-session-store`, `polyspec-session-store-core`,
  `polyspec-session-store-file` and `polyspec-session-store-redis`, the Composer package `polyspec/session-store` with
  the namespace `Polyspec\SessionStore` and the extension `polyspec_session_store`, the PyPI package
  `polyspec-session-store` with the module `polyspec.session_store`, the npm package `@polyspec/session-store` and the
  error classes `SessionStore<Category>Error`. The contract records the change in `changes`. The dependency on the
  repository php-serialize is the crate `polyspec-php-serialization` of the repository php-serialization.
